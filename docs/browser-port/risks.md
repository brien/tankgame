# Browser-port risk register

| Risk / unknown | Relevant code | Why it matters | Mitigation / validation | Validate early? | Desktop compatibility impact |
|---|---|---|---|---|---|
| Compatibility GL is not WebGL | `GraphicsTask.cpp`, all concrete renderer files | Immediate mode, matrix stack, lighting and display lists cannot be the shipping browser renderer. | Representative shader/VBO PoC; inventory and golden captures; migrate by render pass. | Yes—primary gate. | Shared renderer must run on Linux/macOS/Windows, or retain/test native backend. |
| Rendering pipeline is organizational, not API-isolated | `RenderingPipeline`, `BaseRenderer`, renderer classes | A nominal interface still exposes global GL assumptions and resources. | Put backend boundary after `SceneDataBuilder`; forbid GL types/calls above it; explicit pass/resource contracts. | Yes. | Improves all platforms if introduced without changing simulation. |
| Duplicated legacy/new paths obscure actual behavior | `GraphicsTask` legacy methods vs `src/rendering`; duplicate tank renderers | Porting dead code wastes effort; missing a live fallback loses behavior. | Runtime coverage/instrumentation across game modes and visual fixtures before pruning. | Yes. | Avoids accidental desktop feature regression. |
| `.gsm` loaded as OBJ in new resource manager | `GraphicsTask::PrepareMesh`, `ResourceManager::PrepareMesh`, `igtl_qmesh` | Active resource path may silently fail or use fallback; browser parity target is unclear. | Trace runtime loads; unit test representative GSM counts/bounds/normals; define one CPU mesh loader contract. | Yes. | Fix later through shared loader and test equivalence on all desktops. |
| Texture decoder memory/format assumptions | `TextureHandler.cpp` | Mixed `new[]`/`free`, alignment, legacy clamp, NPOT mip/repeat and channel combinations can fail or expose UB in WASM. | Sanitizer tests; decode-only fixtures; explicit pixel buffers/alignment; capability-aware upload. | Yes. | Shared corrected upload/decoder benefits all targets; compare texture output. |
| Transform/lighting parity | GLU and fixed lighting in graphics/pipeline/renderers | Matrix multiplication order, CW winding, normals and attenuation strongly affect appearance. | CPU matrix unit tests and native reference screenshots for representative scenes. | Yes. | Native captures are acceptance oracle; modern renderer is tested on all desktops. |
| Main loop blocks browser | `TaskHandler::Execute()` | Browser must regain control each frame. | Extract one-frame tick preserving sorted task order; browser scheduler callback; native loop calls same tick. | Yes. | Native owns its loop as before; shared tick reduces divergence. |
| Initialization assumes assets are synchronously present | task `Start()`, `GraphicsTask`, `SoundTask`, `LevelHandler` | Browser downloads/mounts package asynchronously before synchronous reads. | Delay `App` task start until preload completion; loading/error state; deterministic virtual root. | Yes. | Native initialization stays synchronous with same resource manifest. |
| Relative mouse requires gesture | `GameTask`, `InputTask`, `VideoTask` | Immediate `SDL_SetRelativeMouseMode` can be rejected; controls become unusable. | Click-to-play acquisition and lock-lost UI; retain keyboard navigation. | Yes. | Compile/platform policy preserves direct native relative mode. |
| Audio autoplay/codec/mixer support | `SoundTask`, `Tank.cpp`, OGG/WAV assets | Music starts before activation; codecs and positional API behavior may differ. | User-gesture audio resume PoC; verify OGG/WAV and `Mix_SetPosition`; fallback format/interface if needed. | Yes. | Keep SDL_mixer path and identical assets/channels on native. |
| Timer jumps after hidden tab | `GlobalTimer`, movement code | Large `dT` can teleport entities or destabilize collisions. | Visibility pause or reset/clamp policy; deterministic suspension test. | Yes. | Browser event policy only, or shared safe clamp tested not to alter normal native play. |
| Input event model lacks close/hot-plug/focus processing | `InputTask::Update()` | `SDL_PumpEvents` alone does not implement browser lifecycle/controller connection behavior. | Add future event handling while retaining state snapshots; clear state on blur. | Yes. | Test existing mappings and window-close semantics on every desktop. |
| Gamepad mappings vary | joystick handlers | Browser exposes standardized/limited mappings; hats and GameCube assumptions may not map. | Browser hardware matrix; SDL mapping layer; configurable bindings/fallback keyboard. | Medium. | Do not remove native specialized handlers. |
| Static resolution/no resize/high-DPI model | `VideoTask`, `ViewportManager`, projection code | Canvas CSS/drawing size divergence distorts views/HUD; split screen magnifies errors. | Central framebuffer resize event, per-viewport aspect, pixel-ratio policy and screenshot tests. | Medium. | Native fixed mode remains valid; resize support should be cross-platform where enabled. |
| Fonts have duplicate initialization/ownership | `GraphicsTask`, `ResourceManager`, HUD/text code | Double lifecycle and texture creation can leak/fail; browser text parity uncertain. | Single resource owner; glyph-atlas PoC from bundled font; golden text tests. | Medium. | Shared atlas works on every target and avoids platform fonts. |
| File paths/current directory | all asset loaders, `Logger`, `VideoTask` | Browser virtual paths and native launch directories differ. | Resource-root service/manifest; package exact tree; separate writable settings/log path. | Yes. | Native resolver retains runtime-tree compatibility on Linux/macOS/Windows. |
| Persistent settings are asynchronous | `settings.txt` | Browser persistence needs mount/sync; shutdown may not block. | Initially use packaged defaults; later IDBFS/OPFS with explicit async readiness/save state. | No for render PoC. | Native continues ordinary file I/O. |
| `exit(1)` during font construction | `GraphicsTask::GraphicsTask()` | Abrupt browser termination gives poor diagnostics and complicates cleanup. | Future initialization result propagated to loading/error UI; no exceptions around imports. | Medium. | Native may return failure with same visible error rather than lose support. |
| Assimp/native dependencies in CMake may be unnecessary or difficult | root/src `CMakeLists.txt`, includes in `GraphicsTask` | Emscripten build can be blocked by a dependency not needed at runtime. | Link/use audit; eliminate only if proven unused, or build supported port. | Yes (compile gate). | Never remove native required behavior; native builds remain CI gates. |
| macOS OpenGL deprecation/context constraints | CMake and Apple header branches | A shared modern renderer must actually run within available macOS OpenGL profile; compatibility backend is not future-proof. | Choose conservative shader/VBO subset, create/test macOS core context and shader dialect early. | Yes. | Explicitly protects the required macOS application. |
| Floating-point/UB differences | simulation, mesh/texture parsers, fixed arrays | WASM exposes alignment, lifetime, bounds and precision assumptions differently. | Native/WASM sanitizers where supported; deterministic simulation replays and parser tests. | Yes. | Fixes must preserve rules/results across all platforms. |
| WebGL context loss | renderer/resources | Browser may lose context and invalidate all GPU handles. | Resource catalog retains CPU/reload descriptions and supports recreate; test synthetic loss. | Medium. | Recreation design also handles native context rebuild; no negative target impact. |
| Bundle size/startup | all runtime assets | Preloading unused tracker/JPEG/legacy assets increases first load. | Generate resource manifest from active references; compression/cache; staged loading only after behavior is proven. | Medium. | Native packages may retain full set or use same verified manifest. |
